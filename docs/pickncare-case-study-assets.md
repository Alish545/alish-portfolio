## Portfolio-card copy

PickNCare connects careseekers with individual caregivers and agencies for babysitting, childcare, and elderly care. As Frontend Developer and Mobile App Deployment Lead, I worked across the React website and shared Flutter codebase on booking, localization, payment-related interfaces, and production reliability. I also prepared mobile releases and coordinated with backend developers on purchase verification and review blockers, preserving existing APIs, state management, and business logic.

## Résumé bullets

- Developed React and Flutter frontend experiences for care booking, provider discovery, authentication, and role-based workflows, integrating existing REST APIs with backend-team collaboration.
- Supported four-language localization and payment-related interfaces while separating translated display content from booking state, service payments, subscriptions, and consumable purchases.
- Prepared signed iOS archives and Android App Bundles, managed version/build numbers, and coordinated release notes and investigation of App Store review blockers.
